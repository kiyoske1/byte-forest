# BYTE FOREST — техническое задание MVP 0.1

## Цель
Проверить спрос на Telegram-продукт BYTE FOREST для русскоязычной аудитории СНГ и собирать квалифицированные заявки на разработку Telegram-ботов и автоматизаций.

## Пользовательские сценарии
1. Пользователь открывает бота и видит понятное меню.
2. Пользователь просматривает небольшой каталог цифровых инструментов.
3. Пользователь выбирает категорию промпта и получает шаблон, который может скопировать.
4. Пользователь оставляет заявку на разработку.
5. Администратор получает уведомление о заявке.
6. Заявка сохраняется в D1 для последующей обработки.

## Функциональные требования
- `/start`: приветствие и меню.
- `/help`: краткая инструкция.
- `/tools`: каталог инструментов.
- `/prompt`: меню шаблонов.
- `/order`: начало приёма заявки.
- `/about`: описание BYTE FOREST.
- `/status`: техническая проверка, только для администратора.
- Webhook endpoint `/webhook`.
- Проверка заголовка `X-Telegram-Bot-Api-Secret-Token`.
- Сохранение заявок в таблице `leads`.
- Хранение шага диалога в `user_state`.
- Уведомление администратора о новой заявке.

## Нефункциональные требования
- Не хранить токен в исходном коде.
- Не использовать платные AI API в MVP.
- Не запрашивать пароли, платёжные данные или чувствительную информацию.
- Обрабатывать ошибки Telegram API без раскрытия секретов.
- Минимизировать персональные данные: Telegram ID, username (если есть), текст заявки, дата.
- Предусмотреть возможность удалить заявку по запросу пользователя на следующем этапе.

## Вне объёма MVP
- Оплата и подписки.
- AI-генерация через внешние API.
- Автопостинг в канал.
- CRM и массовые рассылки.
- Сложная аналитика.

## Критерии приёмки
- `/start` возвращает меню.
- Каталог и шаблоны доступны через inline-кнопки.
- Заявка проходит от начала до подтверждения.
- Запись появляется в D1.
- Администратор получает уведомление.
- Неверный webhook secret отклоняется.
